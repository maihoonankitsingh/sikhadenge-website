# Claude V11 — Responsive Real Work Image Section

This package replaces the old dark placeholder-avatar strip with a responsive image-backed section.

- Desktop: generated 2172×724 wide premium visual.
- Tablet: same wide visual with tighter responsive copy.
- Mobile: generated 1122×1402 vertical visual.
- Important text remains HTML/CSS, not baked into the image.
- Workflow labels remain readable on all viewport sizes.
- Registration and backend/tracking/payment logic remain untouched.
- Installer creates a backup and does not build or restart PM2.
